# Weapon-free sports source kit

Generated 2026-11-04 with the built-in OpenAI ImageGen tool. The eight `action-{facing}.png` sheets contain 16 authored poses each, matching the original armored athlete identity without bats. The existing polished-v1 inputs and original atlas remain separate. `arena-unmarked.png` is a generated edit removing painted floor markings; only its registered floor polygon is extracted, retaining existing surrounding architecture.

Rebuild with `.venv-assets/bin/python scripts/game-assets/import-cryptball-sports.py`. Output: `public/assets/cryptball-sports/manifest.json` and three 1024² atlas pages. Extraction uses connected components, alpha threshold 210, one shared 64-color palette, nearest sampling to 44px standing height, foot pivot (56,70) on a 112×80 canvas, and six constrained teal-uniform material palettes. No anatomy is drawn by the importer. Source hashes and crop coordinates are in `extraction.json`; structural checks in `runtime-qa.json`.

Rows: idle/run A/run B/run C; run D/slide/recovery low/recovery up; kick windup/contact/follow/receive; set/jump/spike/land. All eight sheets and the final native-resolution contact sheet were visually inspected: empty hands, complete figures, distinct kick/receive/set/spike silhouettes. Adjacent east/southeast and west/southwest views are close; generated directional transitions are not hand-cleaned. These are key-pose animations, not a full hand-authored inbetween set.

Aliases are explicit in the manifest: pass uses the three kick poses; trap uses kick contact then idle; dig uses separately generated hands-first contact/push-up poses from `../dives-v1`; active volleyball dives use launch/flight/contact and recover through push-up; sprint uses the run cycle; recoil uses recovery; celebration uses set then idle. Receive, set, jump, spike and land are distinct generated poses. The additional four dive poses per facing are recorded independently in `../dives-v1`; source sheets here remain the original sixteen poses. No weapon removal is claimed through renaming. Volley jumps are cosmetic action/contact lifts; simulation owns ball height and does not simulate player vertical movement.

The presenter selects kick/pass from action kind and phase; volley contact events select attack/set/dig at their authoritative tick. Tick-based sampling freezes poses during pause. Net x=0 and height24 match the simulation; depth segments allow near actors to cover far mesh. Ball height offsets ball/trails while the shadow stays on the floor. The landing ellipse predicts an uninterrupted ballistic flight and disappears if the prediction lies outside court; future contacts and walls can change it.

`prompts.json` records the directional prompt set and floor-edit prompt. Runtime filenames and source attribution are also recorded in `public/assets/cryptball-sports/LICENSES.txt`.
